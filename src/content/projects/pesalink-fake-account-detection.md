## Overview

This project was developed for the Pesalink Fintech AI Hackathon to detect fake accounts in high-volume payment processing. The solution uses a machine learning model for secure batch account validation and includes feature engineering and data exploration on fintech datasets to identify malicious activity.

## Features

- Machine learning model for fraud detection
- Secure batch account validation
- Feature engineering and data exploration
- High model accuracy and low-latency processing
