## Overview

Trip Calculator is a desktop application designed to help users estimate the total fuel required and overall cost for a journey. It leverages the OpenRouteService API to calculate accurate road distances between an origin and multiple stops, enabling precise trip planning.

The application includes a graphical user interface for ease of use, along with functionality to save trip data and manage recurring activities, making it suitable for both casual and repeated travel planning.

## Features

- Fuel consumption calculation based on distance and efficiency  
- Total trip cost estimation using fuel price input  
- Integration with OpenRouteService API for accurate routing distances  
- Save trip data to Excel files for record-keeping  
- Load and manage saved activities  
- User-friendly GUI built with Tkinter  

## Tech Stack

- Python  
- Tkinter  
- OpenRouteService API  
- Openpyxl
