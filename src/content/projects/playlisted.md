## Overview

Playlisted is a web-based analytical game that uses the Spotify API to fetch and process user playlist data for interactive gameplay. The backend is built with Laravel and PHP, and a structured SQL database manages user scores and song metadata.

## Features

- Interactive gameplay based on Spotify playlist data
- Structured SQL database for user scores and metadata
- Data integrity and robust backend

## Tech Stack

- Laravel
- PHP
- SQL
- Spotify API
