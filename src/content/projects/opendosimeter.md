## Overview

OpenDosimeter is a project focused on modernizing radiation safety hardware. The team refactored legacy code for improved maintainability and scalability, and enabled IoT capabilities via Bluetooth for real-time monitoring of healthcare worker safety data.

## Features

- Modernized legacy radiation safety hardware
- Real-time monitoring via Bluetooth
- Improved maintainability and scalability
- Stakeholder collaboration for technical specifications
